# Real-World Examples

## Remove Duplicate Names

```python
students = ["Ram", "Sita", "Ram", "Krishna"]

unique_students = set(students)

print(unique_students)
```

Output:

```text
{'Ram', 'Sita', 'Krishna'}
```

## Common Subjects

```python
student1 = {"Math", "Science", "English"}
student2 = {"Science", "English", "History"}

print(student1 & student2)
```

Output:

```text
{'Science', 'English'}
```
