# Real-World Examples

## Sum of Numbers 1 to 10

```python
total = 0

for i in range(1, 11):
    total += i

print(total)
```

Output:

```text
55
```

---

## Count Down Timer

```python
count = 5

while count > 0:
    print(count)
    count -= 1

print("Time's Up!")
```

Output:

```text
5
4
3
2
1
Time's Up!
```
